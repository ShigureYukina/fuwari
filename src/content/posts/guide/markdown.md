# Markdown 语法指南

本文将会介绍 Markdown 的基本语法和使用方法。通过一些简单的示例，辅助你快速掌握 Markdown 的写作技巧。

## 基本文本格式

段落之间需要使用空行分隔。这样可以让文本结构更加清晰。

你可以使用以下方式来强调文本：
- _斜体文本_ 使用单个下划线
```
_斜体文本_ 
```
- **粗体文本** 使用双星号
```
**粗体文本**
```
- `代码文本` 使用反引号
```
`代码文本`
```

## 列表

### 无序列表
使用减号、加号或星号作为列表标记：
- 第一项
- 第二项
- 第三项
```
- 第一项
- 第二项
- 第三项
```

### 有序列表
使用数字加点来创建有序列表：
```
1. 第一步
2. 第二步
3. 第三步
```

1. 第一步
2. 第二步
3. 第三步

## 引用

使用 > 符号来创建引用块：

> 这是一个引用示例。
> 引用可以包含多行文本。
>
> 也可以包含多个段落。
```
> 这是一个引用示例。
> 引用可以包含多行文本。
>
> 也可以包含多个段落。
```

## 代码

### 行内代码
使用反引号来标记行内代码：`print("Hello World")`(就像上面强调文本所提到的)
```
`print("Hello World")`
```
### 代码块
可以使用缩进或围栏式代码块：

```python
import time

# 一个简单的计时示例
for i in range(10):
    time.sleep(0.5)    # 暂停0.5秒
    print(f"计数：{i}")
```

## 其他语法

### 水平分割线
使用三个或更多的星号、减号或下划线：
```
---
```
---

### 转义字符
使用反斜杠来显示特殊字符：
```
\*这不是斜体\*
```

### 脚注
